# 📚 Books Recommender System

A Machine Learning based **Book Recommendation System** that suggests similar books based on user preferences using **Cosine Similarity** and **Collaborative-Based Filtering**.

The application provides **real-time book recommendations** through an interactive Streamlit interface.


## 🚀 Live Demo

### 🌐 Streamlit App

https://e2e-books-recommender-system.streamlit.app

### 📂 GitHub Repository

## 📌 Project Overview

This system recommends books based on:

* Selected book title
* Similarity score
* User preferences
* Book metadata

The model provides:

* 📚 Top Similar Books
* ⭐ Personalized Recommendations
* 🎯 Fast Predictions
* 🎨 Interactive UI


## 🧠 Architecture


## ⚙️ How to Run Locally

### Clone Repository

```
git clone https://github.com/maitriishahh/Books-Recommender-System.git
cd Books-Recommender-System
```

### Install Dependencies

```
pip install -r requirements.txt
```

### Run Streamlit

```
streamlit run app.py
```
